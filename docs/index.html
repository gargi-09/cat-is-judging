Catch the claims an AI agent can't back up.

Cat-is-Judging is an open-source neurosymbolic faithfulness auditor for LLM agents. It checks every claim an agent makes against deterministic ground truth, then fuses that with multi-sample consistency into one score. The flagship demo is maritime: reconciling Sentinel-2 satellite imagery with AIS transponder data to expose dark vessels, spoofers and phantom signals.

Results on real data

The simulator is synthetic; these numbers are not. One day of AIS (2026-03-03, 52,548 fixes, 182 vessels) reconciled against 475 annotated ships in 183 Sentinel-2 chips over the Gulf of Oman.

99.5%blind-association precision (labels ignored, then used to score)
97.5%blind recall on ships AIS can place at image time
0.4%false dark-vessel alarms (2 of 475)
10spoofing candidates from identity checks, 1.4–58 km off
71AIS reception gaps correctly not flagged as threats
−70%false spoofing alerts after fixing a timestamp trap

Auditor on the same data (Phase 2)

Each of three stand-in analysts wrote one report per tile (183 tiles), re-sampled 5 times for consistency, and the guardrail decided what would be released. The analysts are placeholders until Phase 3; the point is how the guardrail treats each failure mode.

AnalystPassAmendBlockWhat it shows
imagery_first137460Amended reports are tiles where AIS gaps leave “no dark vessels” unprovable: hedged, not asserted
ais_trusting1155414Positions with no hull behind them are cut. 12 blocks: mostly unsupported reports. 2 blocks: “no dark vessels” where blind association has a candidate, which are its 2 known false dark alarms, so the auditor is only as good as its rules
alarmist1153335Going-dark accusations on short AIS gaps are unverifiable; where AIS did place the ship, the report is blocked

Honest limits: every annotated ship in this dataset is a real AIS vessel (labels were made by matching to AIS), so there are no true dark vessels to find. That is why blind mode is scored against the labels, and why dark-vessel and spoofing behaviour is demonstrated with injected cases. All alerts are candidates for review, not proof.

That last one is the project in miniature: the feed's eta column says UTC+8, but an offset sweep proved positions are UTC. Trusting the obvious reading would have flagged ordinary ships as spoofers, which is exactly the kind of confident, unfounded conclusion the auditor exists to catch.

Quick start

You're already in the fastest way to try it: everything above runs in your browser. To run the code locally (Python 3.10+), install it and run the test suite. The tests use small synthetic fixtures, so no dataset is needed.

# clone, install and run the tests
git clone https://github.com/gargi-09/cat-is-judging.git
cd cat-is-judging
python -m venv .venv
.venv/bin/python -m pip install -r requirements.txt     # Windows: .venv\Scripts\python
python -m pytest

Have the raw data? The AIS and Sentinel-2 files aren't distributed with the repo. If you have them, place them under applications/maritime_threat_detection/data/raw/ and run python -m applications.maritime_threat_detection.scripts.ingest_telemetry to build the database and reproduce the results above.

Everything on this page runs in your browser on simulated data, using a JavaScript port of the repository's reconciliation rules (500 m + estimate-uncertainty tolerance, 1 h interpolation, 300 m stationary hold, 30 min dead reckoning, 30 m dark-vessel size gate, 12 h going-dark rule) and of the auditor core (0.95 pass threshold, 0.5 cap for unverified claims, block below 0.5 or on a contradicted critical claim).
